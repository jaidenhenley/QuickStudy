# es-ES: differences from es-419 only (tú, Spain)

Everything else is identical to es-419.

| es-419 | es-ES | Why |
|---|---|---|
| agregar / agrega / agregada / se agregará | añadir / añade / añadida / se añadirá | "Añadir" is Spain's default verb |
| Alcanzaste, Usaste, Superaste, Fallaste | Has alcanzado, Has usado, Has superado, Has fallado | Spain uses the present perfect for recent past |
| Longest was ... "fue de" | "ha sido de" | Same tense preference |
| Tarjetas que escribiste | Tarjetas que has escrito | Present perfect |
| Demasiadas solicitudes | Demasiadas peticiones | Common Spain term |
| conteos anónimos | recuentos anónimos | Spain: "recuento" |
| Se perderán tus ediciones | Se perderán tus cambios | More natural in Spain |
| cuestionario / opción múltiple (listing) | test / tipo test (listing) | Spain says "test" |
| listing keywords | flashcards, test, oposiciones | Spain search terms |
| listing: "se carga a tu cuenta" | "se cobra en tu cuenta" | Natural payment wording |

Kept the same on purpose: Ajustes, Fototeca, Archivos, Llavero, Cámara, Listo, "app", "iPhone", conjunto, tarjeta, apuntes, pág.
